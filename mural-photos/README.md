# Mural photos

Drop photos into the folder matching the mural's slug, e.g. `la-chica/1.jpg`, `la-chica/2.jpg`.
- Files sort by name; the first one becomes the card cover.
- JPG, PNG, WebP or HEIC are fine; large originals are OK (they get resized).
- Not sure which mural a photo is? Put it in `unsorted/`.
